# RT Key Digital Twin

Кликабельный прототип мобильного приложения для управления домофоном, камерами, временными кодами доступа и историей событий.

## Статус

Рабочая версия прототипа перенесена в портфолио-репозиторий как proof-of-work артефакт.

Это не production-приложение и не официальный продукт. Прототип сделан для учебного продуктового анализа, демонстрации сценарного мышления и быстрой материализации UX-гипотез.

## Что показывает кейс

- Декомпозицию мобильного продукта на ключевые пользовательские сценарии.
- Работу с состояниями интерфейса: loading, success, error, unavailable, paywall.
- Разделение сущностей: домофон, внешние камеры, временные коды, история событий.
- Тарифные ограничения base / premium как часть продуктовой логики.
- Быструю сборку интерактивного прототипа на React, Vite и мок-данных.

## Основные сценарии

- Открыть дверь через домофон.
- Принять входящий звонок по аудио или видео.
- Обработать premium-ограничение для видеоответа и архива.
- Посмотреть камеры и открыть карточку камеры.
- Создать и удалить временный код доступа.
- Посмотреть историю событий.
- Переключить тарифный режим в профиле.

## Как запустить

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Что сознательно вне scope

- Реальный backend и авторизация.
- Интеграция с настоящими камерами, RTSP/HLS или внешними API.
- Реальные пользовательские данные.
- Официальные брендовые ассеты.
- Полный pixel-perfect перенос исходного приложения.
