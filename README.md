# Product Dev Portfolio

Публичный репозиторий портфолио для кейсов по Product Management, workflow, operations и automation.

## Структура

- `cases/` - публичные кейсы и proof-of-work артефакты.
- `docs/` - правила публикации, чек-листы и рабочие заметки по проекту.
- `assets/` - публичные изображения, схемы и обезличенные скриншоты.
- `templates/` - шаблоны для новых карточек кейсов.

## Текущий фокус

Кейсы в работе:

- `cases/dwtech-shipment-card/`
- `cases/rt-key-digital-twin/`

## Правило публикации

В репозиторий попадают только очищенные и публично-безопасные материалы. Приватные заметки, внутренние ссылки, credentials, ID документов, локальные пути, имена поставщиков и конфиденциальные документы остаются за пределами этого репозитория.
