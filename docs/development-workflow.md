# Рабочий алгоритм разработки

## Рабочая модель

- Obsidian - приватная база знаний и черновая зона.
- Этот репозиторий - публичная витрина портфолио.
- Из Obsidian сюда переносятся только очищенные идеи и артефакты.

## Цикл разработки кейса

1. Выбрать один кейс.
2. Заполнить карточку: проблема, роль, решение, доказательства, статус.
3. Проверить безопасность публикации.
4. Добавить обезличенные артефакты.
5. Сделать локальный коммит.
6. Запушить изменения на GitHub.
